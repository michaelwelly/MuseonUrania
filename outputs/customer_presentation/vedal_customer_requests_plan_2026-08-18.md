## 12. Запрет копирования с сайта

Важно: абсолютного запрета копирования в браузере не существует. Можно усложнить копирование, но нельзя запретить скриншоты, DevTools и сохранение сетевых файлов.

Реалистичный набор мер:

1. Для текстов:
   - отключить выделение/copy/context menu на чувствительных блоках;
   - добавить предупреждение об авторских правах;
   - не размещать чувствительные тексты публично.
2. Для изображений:
   - запретить drag/save context menu;
   - отдавать изображения в оптимизированном web-формате, без оригиналов;
   - добавить легкий водяной знак там, где это допустимо.
3. Для документов:
   - не отдавать приватные PDF прямой ссылкой;
   - публичные документы отдавать только после согласования;
   - внутренние документы показывать после логина и логировать скачивания.
4. Для AI:
   - не индексировать confidential-документы;
   - public/internal/confidential должен быть обязательным полем документа.
