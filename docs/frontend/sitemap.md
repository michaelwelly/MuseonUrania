# Карта сайта

**Русский** · [English](sitemap.en.md)

Состояние публичных маршрутов `vedal-med.ru` на 16 сентября 2026 года.

## Глобальная навигация

Порядок видимых пунктов: «О компании», «Производство», «Продукция», «Сервис»,
«Новости», «Контакты». Пункт «Документы» описан в конфигурации навигации, но
скрыт общим выключателем публичных документов. Главная открывается по знаку
VEDAL в шапке.

Постоянные элементы: знак VEDAL, телефон, кнопка связи и плавающая кнопка
Ведалины.

## Постоянные редиректы

`frontend/next.config.ts` разворачивает таблицу ниже в 39 постоянных
редиректов по путям. Next.js принимает вариант источника как со слэшем, так и
без него. Сороковое правило относится к имени хоста и описано после таблицы.

| Канонический адрес | Источники |
| --- | --- |
| `/` | `/home`, `/main`, `/index`, `/glavnaya` |
| `/about/` | `/about-us`, `/o-kompanii`, `/o-nas`, `/company`, `/partners` |
| `/production/` | `/proizvodstvo`, `/manufacturing`, `/production/archive` |
| `/products/` | `/product`, `/catalog`, `/katalog`, `/produkciya`, `/produktsiya` |
| `/service/` | `/servis`, `/service-request`, `/support` |
| `/news/` | `/new`, `/novosti`, `/press`, `/blog` |
| `/contacts/` | `/contact`, `/contact-us`, `/kontakty`, `/kontakti` |
| `/legal/privacy/` | `/legal`, `/privacy`, `/privacy-policy`, `/policy`, `/politika-konfidencialnosti` |
| `/products/vedal-r1/` | `/products/vedal-r1-r2` |
| `/` | `/en`, `/en/:path*`, `/zh`, `/zh/:path*` |
| `/:path*/` | `/ru/:path*` — тот же путь без русского префикса; правило также покрывает `/ru` |

Английские и китайские адреса ведут на русскую главную, потому что
согласованных переводов содержимого нет. Русский префикс сохраняет путь:
`/ru/products/` → `/products/`.

В `next.config.ts` также есть host-правило `www` → адрес без `www`, но боевой
шлюз не сохраняет исходный `Host`, поэтому оно не решает дубль домена на
текущем периметре. Канонизацию нужно выполнить в nginx; до этого вопрос
остаётся открытым.

## Отложенные маршруты

| Маршрут | Страница | Почему отложено |
| --- | --- | --- |
| `/technology/` | Разработка и технологии | требуется согласование R&D и публичных утверждений |
| `/cases/` | Кейсы | нужны согласия заказчиков и подтверждённые материалы |
| `/en/`, `/zh/` | Переводы сайта | нет согласованных переводов содержимого; адреса сейчас редиректятся |
| `/hi/` | Версия на хинди | более поздний этап выхода на рынок |
| `/knowledge/` | Внутренний портал знаний | закрытый контур, не публичный релиз |

Ни одна публичная страница не должна публиковать несогласованные сведения о
ценах, наличии, сроках поставки, клинических результатах, сертификатах или
регистрационном статусе.
