# Проверка живости

**Русский** · [English](monitoring.en.md)

## Что проверяется

`scripts/healthcheck.sh`, таймер `vedal-health.timer`, раз в пять минут:

- портал отвечает `UP` на `/actuator/health`;
- главная страница отдаёт 200;
- свои контейнеры (`vedal-*`) запущены и здоровы;
- диск занят меньше чем на 85%;
- в очереди писем нет застрявших в разборе и не копится отправка.

## Почему изнутри машины

Снаружи ответ портала смешан с состоянием канала. 7 сентября 2026 один
и тот же адрес отвечал и не отвечал с интервалом в минуту, при том что
стек был здоров и по `127.0.0.1:18080` отдавал страницы за шесть
миллисекунд. Проверка, ходящая снаружи, будила бы по ночам из-за чужого
маршрутизатора.

Обратная сторона: недоступность стенда для посетителя эта проверка
не увидит. Её увидит внешний монитор, и он появится вместе с доменом —
по домену и 443 канал ведёт себя иначе.

## Оповещение

Тревога поднимается **на переходе состояния**, а не на каждом тике: иначе
оповещения превращаются в фон, который перестают читать. Состояние лежит
в `/var/lib/vedal/health.state`.

В журнал — всегда: `journalctl -u vedal-health`. Наружу — если задан
`VEDAL_ALERT_WEBHOOK` в `backend/.env`: адрес, принимающий
`POST {"text": "..."}`. Подходит бот Телеграма, вебхук мессенджера
или что угодно, что умеет принять JSON.

## Установка

```bash
sudo cp /opt/vedal-portal/scripts/vedal-health.service /etc/systemd/system/
sudo cp /opt/vedal-portal/scripts/vedal-health.timer /etc/systemd/system/
sudo mkdir -p /var/lib/vedal && sudo chown ubuntu:ubuntu /var/lib/vedal
sudo systemctl daemon-reload
sudo systemctl enable --now vedal-health.timer
```

Проверить сразу: `sudo systemctl start vedal-health.service`.

## Настройки

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `VEDAL_HEALTH_URL` | `http://127.0.0.1:18080` | адрес шлюза изнутри машины |
| `VEDAL_HEALTH_DISK_PERCENT` | `85` | при каком заполнении диска тревожить |
| `VEDAL_HEALTH_QUEUE` | `50` | сколько писем в очереди считать затором |
| `VEDAL_ALERT_WEBHOOK` | пусто | куда слать тревогу наружу |
