## Monthly Support

Monthly support after project completion: 15,000 RUB/month.

Support includes:

- Basic technical support for the deployed website and admin panel.
- Monitoring of Yandex VM and production availability.
- Operational support for Yandex Metrica and basic analytics checks.
- Included operating budget for current Yandex VM and Yandex LLM API tokens within agreed usage.

Not included by default:

- Large GPU VM for local LLM/VLM.
- Migration from Yandex LLM API to local LLM/VLM.
- Major new website sections or product-line expansion.
- Large-scale advertising campaign management.

If VEDAL decides to deploy a large VM with local LLM/VLM, this should be scoped as a separate integration phase.
