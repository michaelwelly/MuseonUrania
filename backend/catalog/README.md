# catalog

Продукция и категории. Публичное API, из которого сайт берёт каталог.

Модель — [content_model.md](../../docs/frontend/content_model.md) → Product Model:
идентификатор, slug, название, категория, приоритет, статус публикации, назначение,
преимущества, публичные характеристики, статус регистрации, медиа, документы,
типы CTA, готовность языков, ответственный за согласование.

Ключевое правило: наружу отдаются только позиции с подтверждённым статусом
публикации. Характеристики публикуются в том виде, в каком согласованы, —
см. [HANDOFF.md](../../HANDOFF.md).

Сейчас те же данные захардкожены во фронтенде (`frontend/content/products.ts`).
Этот модуль их заменит.
