# crm

Лиды, клиенты, сделки, коммерческие предложения, статусы. Пишем сами, внутри
портала — решение из [брифа собственника](../../docs/architecture/vedal_portal_owner_brief.md).

Требования из [functional_requirements.md](../../docs/strategy/functional_requirements.md):
приём лидов с сайта, отметка интереса к изделию, воронка КП, дилерская и сервисная
воронки, назначение ответственного, история переписки и звонков, вложения из
согласованных документов, аналитика по изделию, источнику, языку и кампании.

Причина держать это у себя, а не в почте: «клиентская база не живёт в почте»,
«сделки и КП ведутся в одном месте», «собственник видит управляемую картину».

Лид приходит только из [gateway](../gateway/). Наружу пишет только через
[notifications](../notifications/).
