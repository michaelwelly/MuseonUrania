# common

**Русский** · [English](README.en.md)

Общее для всех модулей: базовые типы, ошибки API, правила валидации,
работа со временем и идентификаторами.

Правило: сюда попадает только то, что нужно двум и более модулям. Один
потребитель — код остаётся у него.

## Модуль сборки

`portal-common` — модуль Maven со своим `pom.xml` и своим `src/`. Зависит от: ни от кого.

Внешнее: Kafka и actuator — их не видит больше никто.

Границу держит сборка, а не дисциплина: импорт из модуля, которого нет
в зависимостях, роняет компиляцию. Раньше весь код лежал одной кучей
в `backend/src/`, и удержать границы можно было только вниманием.
