# documents

**Русский** · [English](README.en.md)

Документы и медиа: метаданные, статус публикации, хранение в объектном хранилище.

Модель — [content_model.md](../../docs/frontend/content_model.md) → Document Model:
тип документа, статус публикации, чувствительность (public / internal / confidential),
язык, связанные изделия, файл, владелец-источник, статус согласования, кто согласовал,
редакция.

Требования из [functional_requirements.md](../../docs/strategy/functional_requirements.md):
публичный бакет или CDN только для согласованных материалов, приватные бакеты для
чувствительного, доступ по ролям, версионирование, правила жизненного цикла.

Жёсткие правила:

- Приватные бакеты по умолчанию, подписанные ссылки для закрытых файлов.
- Ни один документ не становится публичным без явного согласования.
- Сервисные инструкции, конструкторская и производственная документация публично
  не размещаются ([content_and_seo_plan.md](../../docs/strategy/content_and_seo_plan.md) → Sensitive Data Split).

Каждое обращение к закрытому файлу пишется в [audit](../audit/).

## Модуль сборки

`portal-documents` — модуль Maven со своим `pom.xml` и своим `src/`. Зависит от: `common`, `audit`.

Внешнее: AWS SDK для S3 — единственный модуль, который против него компилируется.

Границу держит сборка, а не дисциплина: импорт из модуля, которого нет
в зависимостях, роняет компиляцию. Раньше весь код лежал одной кучей
в `backend/src/`, и удержать границы можно было только вниманием.
