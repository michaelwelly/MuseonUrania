# content

Новости и пресс-центр. Модуль появился из
[спеки архитектуры](../../docs/superpowers/specs/2026-08-06-vedal-portal-architecture-design.md),
в исходном списке модулей его не было.

Код: `src/main/java/ru/vedal/portal/content/`.

Наружу показывает один интерфейс — `ContentQuery`: лента опубликованного и
карточка публикации. Им же пользуется [assistant](../assistant/), поэтому
неопубликованный черновик в ответ ассистента попасть не может.

`published` и `published_on` — разные вещи: первый управляет видимостью, второй
задаёт дату в ленте. Материал готовят заранее, а публикуют позже. Опубликованная
запись без даты запрещена ограничением схемы.

## Данных нет и это нормальное состояние

`frontend/content/news.ts` пуст: материалы Иннопрома числятся в «Awaiting NN»
(см. [nikolay_materials_request.md](../../docs/requests/nikolay_materials_request.md)),
а демо-публикации из макета в прод не переносим — прямое указание
[HANDOFF.md](../../HANDOFF.md). Поэтому у модуля нет сида: пустая лента отдаёт
`[]`, а первую запись добавляет редактор через админку.

Слаг публикации ограничен латиницей: он уходит в публичный URL.
